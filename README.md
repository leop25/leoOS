# Leonardo Penna de Lima - LeoOS

Static personal site that emulates a classic Macintosh desktop.

## Files

- `index.html`: desktop, windows and content.
- `styles.css`: classic Mac visual system.
- `app.js`: window manager, terminal commands and easter eggs.
- `assets/fonts/sysfont/`: Sysfont webfont, an OFL revival of classic Macintosh Chicago.

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```
